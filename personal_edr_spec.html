Project overview
PersonalEDR
ETW 기반 개인용 행위 분석 도구. Procmon의 raw event dump 방식을 탈피하여 프로세스별·행위별 클러스터링 및 타임라인 기반 시각화에 집중. 상용 EDR과 달리 공격자 우회 대상이 되지 않는 개인 모니터링 레이어 목적.
Rust (백엔드) Tauri 2.0 React + TypeScript DuckDB Windows 10/11 관리자 권한 필요

이벤트 스키마
struct Event {
ts: i64, // unix ns
pid: u32,
ppid: u32,
proc_name: String,
category: Category, // Process|File|Network|Registry|ImageLoad
op: String, // Create|Write|Connect|SetValue ...
target: String, // 경로 or IP:port or 레지스트리 키
severity: u8, // 0=normal 1=suspicious 2=alert
meta: JsonValue // 카테고리별 추가 필드
}
클러스터링 / 노이즈 압축 로직
반복 이벤트 접기
동일 (pid, category, target_pattern) 조합이 60초 내 N회 이상 발생 시 하나의 집계 노드로 표시. 기본 임계값 N=10, 사용자 조정 가능.
화이트리스트 기반 정상 분류
TOML 파일로 관리. 프로세스명·경로 패턴·도메인 단위 지정. 화이트리스트 이벤트는 타임라인에서 흐리게 처리, 완전 숨김 옵션.
[[whitelist]]
proc = "chrome.exe"
category = "network"
target_pattern = "*.google.com"
첫 발생 강조
세션 시작 이후 해당 (proc, category, target) 조합이 처음 관찰되면 "new" 배지 부착. 분석 집중 포인트 제공.
UI 구조
모드 전환
모니터링 모드 실시간 슬라이딩 윈도우 (기본 10분), 자동 스크롤
조사 모드 시간 범위 고정, 자유 탐색, 프로세스 핀 고정, 이벤트 북마크
메인 레이아웃 — 3패널
좌: 프로세스 트리 (트리 노드 클릭 → 해당 프로세스 포커스)
중: Swimlane 타임라인 (Y=프로세스, X=시간, 밀도=히트맵)
우: 이벤트 상세 슬라이드인 패널 (클릭 시 열림)
Swimlane 타임라인 상세
- 프로세스당 메인 레인 + 카테고리별 서브레인 (접기/펼치기)
- 이벤트 밀도 히트맵 (색상 농도 = 빈도)
- 구간 드래그 → 해당 구간 이벤트 집계 팝업
- 줌: 마우스휠 or 핀치 (1초 ~ 1시간 범위)
- severity=alert 이벤트: 레드 오버레이 + 레인 상단 마커

파일 접근 경로 트리 + 프로세스별 색상
인과관계 추적
이벤트 클릭 시 해당 이벤트로부터 downstream 이벤트를 연결선으로 하이라이트. "이 프로세스가 만든 자식" "이 파일에 접근한 다른 프로세스" 자동 연결.
